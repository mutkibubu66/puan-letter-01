## The letter

> Z

One letter, and the day behind it is instantly clear. The sponsor's own
example word is **zero sleep** — and Z also reads as **zombie** /
**zonked**: the bleary-eyed shuffle to the kettle, the third coffee that
does nothing, the day lived on autopilot. Vivid (you can see the
shamble), funny (everyone has lived it), true (no performance, just an
honest report of a day with no sleep in it). Of all twenty-six letters,
Z carries the most striking hidden word.

## Run it

```sh
python3 main.py
```

This writes exactly `Z` to `/output/entry.txt` — 1 byte, no trailing
newline, valid UTF-8 — inside the gate's 1-to-1 character limit.
